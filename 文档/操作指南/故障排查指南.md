# DONGJIN 故障排查指南

## Neo4j

- `neo4j console` 无法执行：确认已有Neo4j的 `bin` 在PATH。
- 连续潮流启动提示活动拓扑不一致：重新在前端执行P1生成/发布，再启动。

## Memurai

- 状态：`.\scripts\status-memurai.ps1`
- 启动/停止需要Windows服务权限时，请在管理员PowerShell执行脚本。
- 服务保持手动启动，配置上限256 MB，使用 `volatile-ttl` 淘汰策略。

## Python

- 使用项目已有虚拟环境，不要安装到C盘全局Python。
- 健康接口：`http://127.0.0.1:8001/health`
- 模型不兼容：执行 `check_inference_model.py --model-id ...` 查看具体字段。

## Java/前端

- Java默认连接 `http://127.0.0.1:8001`。
- 前端接口错误先确认Java 8080和Python 8001均已运行。
- 页面有动态数据但不能研判：这通常表示尚未人工选择模型。
- 研判档案较多：先运行 `cleanup_diagnosis_archives.py` 预览，确认后加 `--apply`。

## 短路

- 缺少 `sScMva/rx`：必须从可信数据源提供。
- 单相接地被拒绝：P1缺少零序线路和外部电网参数，这是数据边界而非程序崩溃。
