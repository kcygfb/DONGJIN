# DONGJIN 模型操作指南

模型生成、评估、选择和回滚是四个独立操作。

1. `train_offline_model.py` 生成模型，不改变在线选择。
2. `evaluate_offline_model.py` 生成独立指标，不改变在线选择。
3. `select_inference_model.py` 先检查P1、图签名、48维顺序、标签、归一化和SHA-256。
4. `rollback_inference_model.py` 恢复上一次已通过兼容检查的人工选择。

所选目录必须含 `model.joblib`、`manifest.json`、`feature-schema.json`、
`label-schema.json` 和 `normalization.json`。

系统不会根据“最新”或“指标最好”自动选择模型。v3只是当前已验证候选，是否选择由
用户决定。详细命令见[最终操作手册](最终操作手册.md)。
